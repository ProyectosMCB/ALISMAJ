# Alismaj · Web de catálogo
HTML + CSS + JavaScript puro. Abre `index.html` o súbela a GitHub Pages.

## Editar contenido
Todo está en `js/data.js`: número de WhatsApp, precios, descripciones, categorías y arreglos.
Para agregar un arreglo copia uno existente y pon su foto en `img/catalogo/<id>.jpg`.

## Publicar en GitHub Pages (gratis)
1. Crea un repositorio (p. ej. `alismaj`) y sube todos estos archivos.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Queda en `https://TU-USUARIO.github.io/alismaj/`. Opcional: dominio propio.
